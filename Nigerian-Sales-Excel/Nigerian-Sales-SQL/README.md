# Nigerian Sales Data Analysis Using SQL

## Overview

This project involved analysing a Nigerian sales dataset using SQL to identify sales patterns and generate business insights.

The analysis focused on querying sales records, grouping data, filtering results and calculating summary statistics to understand product and sales performance.

## Objective

The objective was to use SQL to explore the sales dataset and answer practical business questions about sales performance.

## Tools Used

- SQL

## Analysis

The project involved using SQL queries to:

- Retrieve and filter sales records
- Group sales data by product
- Calculate total sales
- Calculate average sales
- Identify products with higher sales performance
- Sort results to compare sales performance
- Filter grouped results using aggregate conditions

## SQL Concepts Demonstrated

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- HAVING
- Aggregate functions
- Basic data analysis

## Business Questions

The analysis explored questions such as:

1. Which products generated the highest total sales?
2. What was the average sales value?
3. How many units were sold for each product?
4. Which products performed above the average sales level?
5. How can sales performance be compared across products?

## Dataset

The project uses a Nigerian sales dataset containing 550 sales records and fields including:

- Customer Name
- State
- Product
- Units Sold
- Unit Price
- Total Sale
- Sale Date
- Sales Channel
- Order ID
