# Nigerian Sales Data Cleaning & Analysis

## Overview

This project involved cleaning and analysing a 550-record Nigerian sales dataset using Microsoft Excel.

The original dataset contained inconsistent and missing information across customer, product, location and sales fields. The project focused on preparing the dataset for analysis and generating sales summaries.

## Objective

The objective was to clean and organise the dataset and prepare it for meaningful sales analysis.

## Tools Used

- Microsoft Excel

## Data Cleaning

The dataset was cleaned and transformed by:

- Identifying and handling missing values
- Cleaning customer information
- Standardising location and product information
- Cleaning sales-related fields
- Preparing calculated sales values
- Organising the dataset for analysis

## Analysis

The cleaned dataset was used to summarise sales performance, including sales by product.

## Skills Demonstrated

- Data cleaning
- Data transformation
- Excel formulas
- Data organisation
- Sales analysis

## Dataset

The project uses a Nigerian sales dataset containing 550 sales records and fields including:

- Customer Name
- State
- Product
- Units Sold
- Unit Price
- Total Sale
- Sale Date
- Sales Channel
- Order ID
